# Features & Capabilities

## ✨ Core Features

### 🤖 Agent Management
- ✅ Create agents with custom configurations
- ✅ Visual form-based agent creation
- ✅ Support for multiple agents
- ✅ Switch between agents instantly
- ✅ Delete agents
- ✅ View agent details (tool count, model, connector)

### 💬 Chat Interface
- ✅ Real-time streaming responses
- ✅ WebSocket-based communication
- ✅ Message history per agent
- ✅ User and agent message differentiation
- ✅ System messages for tool calls
- ✅ Clear chat functionality
- ✅ Timestamp display
- ✅ Smooth scrolling

- ✅ Live reasoning display during thinking
- ✅ Rolling window of reasoning (last 4 lines)

- ✅ Thinking spinner with preview
- ✅ "View reasoning" expandable sections

- ✅ JSON-based tool definitions
- ✅ Pre-filled example tools
- ✅ Support for async tool execution
- ✅ Parameter schemas with validation
- ✅ Tool call indicators in chat
- ✅ Flexible tool parameters (strings, numbers, arrays, objects)
- ✅ Built-in examples: calculator, time, random numbers, text transform
